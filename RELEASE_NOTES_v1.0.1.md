# Rest POS v1.0.1 Production Release 🎉

An ultra-fast, offline-first Restaurant POS & Billing app built with Flutter, Material 3, and high-performance offline storage.

### 🌟 What's New in v1.0.1
- **Version Footer**: App version (`Rest POS v1.0.1 • Build 2`) is now cleanly displayed at the bottom of the Settings & Configuration screen.
- **Responsive Layout & Zero Overflows**: Comprehensive `FittedBox`, `Expanded`, and `Flexible` defenses applied across all screens to guarantee flawless rendering on devices of all widths (from 320px compact phones to large POS tablets).
- **Accounting & Tax Reconciled**: Daily gross turnover, KPI cards, and GST tax collection are strictly aggregated from settled/paid orders, keeping active dining tables separated until billed.
- **Table Management Lifecycle**: Fixed table freeing and transfer operations to cleanly clear active orders and timestamps.
- **Production Performance**: Full asset tree-shaking (icons reduced by 98.8%), ProGuard bytecode shrinking, and high FPS scrolling.
- **100% Test Coverage**: 28 automated tests passing across accounting models, UI widgets, and screen navigation.

### 📲 Installation
Download the `Rest-POS-v1.0.1.apk` below and install directly onto any Android device running Android 5.0 (API 21) or higher.
